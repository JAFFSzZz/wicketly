# wicketly — Cricket Scoreboard

A simple cricket scoreboard website built with HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and content
- `style.css` — colours, layout, themes and responsive design
- `script.js` — scoring, wickets, innings, player stats and saving
- `README.md` — this guide

## Run in VS Code

1. Extract this ZIP.
2. Open the `crease` folder in Visual Studio Code.
3. Open `index.html`.
4. Install the **Live Server** extension.
5. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser. There is no need for Node.js, React, npm or a database.

## Features

- Custom overs from 1 to 1,000
- Team names, batter names and bowler name
- Runs, extras and wicket scoring
- Batter and bowler scorecards
- Undo the last scoring action
- First and second innings with a target
- Victory celebration
- Light and dark themes
- Browser local-storage save

Match data is saved in the browser on the device being used. It does not automatically sync to other devices.
