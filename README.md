Imagine a sunny cricket ground, green grass, cheering crowds, flying cricket balls and an exciting match waiting to begin.

That's the spirit behind **Wicketly!**

Wicketly is a browser-based cricket scoring application with a playful, cartoon-inspired identity. It brings the excitement of a cricket match into a colourful and easy-to-use scoreboard.

Whether you're playing with friends, organising a friendly match or simply enjoying cricket, Wicketly makes keeping score more fun.

## 🎮 YOUR MATCH. YOUR RULES.

### 🏏 01 — CREATE YOUR MATCH

Get your cricket ground ready!

- Choose your team names.
- Set custom overs from 1 to 1000.
- Select your opening batters.
- Choose your opening bowler.
- Start your match!

### 🏃 02 — LET THE RUNS FLOW!

Take control of the scoreboard.

- Record runs from 0 to 6.
- Add wides and no-balls.
- Record byes and leg-byes.
- Record wickets.
- Track striker and non-striker.
- Follow batter and bowler statistics.
- Undo the previous scoring action.

### 🔔 03 — THE OVER IS COMPLETE!

Six legal deliveries. One completed over.

Wicketly provides an over-completion popup showing the over's runs and match score, with options to continue with the same bowler or select another.

### 🎯 04 — THE BIG CHASE!

The first innings is over. Now the real excitement begins!

- Set the second-innings line-up.
- View the target score.
- See the total balls available.
- Track runs needed.
- Follow balls remaining.
- Watch the match result unfold.

### 🏆 05 — THE FINAL MOMENT!

Will your team chase the target or defend its score?

Follow the match to its conclusion and celebrate the winner!

## 🚀 READY TO ENTER THE GROUND?

Want to run Wicketly on your own computer?

### 🖥️ LOCAL SETUP

**STEP 1:** Clone the repository.

```bash
git clone https://github.com/JAFFSzZz/wicketly.git
```

**STEP 2:** Open the project folder.

```bash
cd wicketly
```

**STEP 3:** Open it in Visual Studio Code.

```bash
code .
```

**STEP 4:** Open `index.html` in your browser or use the Live Server extension.

**STEP 5:** Set up your teams and START PLAYING! 🏏
